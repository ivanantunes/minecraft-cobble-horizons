CobbleHorizons é um modpack Fabric para Minecraft 1.21.1 criado para transformar o mundo do Minecraft em uma aventura Pokémon completa. Exploração, captura, treinamento, batalhas, ginásios, progressão e imersão formam uma única experiência.

## Visão do projeto

O objetivo não é criar um modpack genérico que apenas contém Pokémon. Cada mod, configuração e resource pack deve contribuir diretamente para uma jornada Pokémon em mundo aberto, mantendo desempenho, estabilidade e uma identidade visual própria.

## Destaques

- mundo e estruturas voltados à exploração Pokémon;
- treinadores, ginásios, insígnias e progressão;
- Mega Evolution, breeding, TMs/TRs, Pokédex e navegação;
- mapas, waystones, economia e qualidade de vida;
- áudio ambiente, battle tracks e shaders opcionais;
- stack de desempenho ajustada para uma experiência estável;
- interface própria com logo, wallpapers, ícones e botões CobbleHorizons.

## Identidade visual

A v0.8 utiliza Drippy Loading Screen no boot e FancyMenu na interface. Os estilos globais aplicam background, cores e estados de botões às telas compatíveis; o menu principal possui um layout dedicado.

## Teste da v0.8

1. Importe a última base MRPack no Modrinth.
2. Copie os arquivos atuais do repositório para a raiz da instância.
3. Confirme a substituição dos configs existentes.
4. Inicie o jogo e execute docs/testing.md.
5. Analise logs/latest.log.
6. Após aprovação, exporte um novo MRPack.

## Estabilidade

Uma alteração só é considerada aprovada após boot, carregamento de mundo, captura, batalha, interfaces, progressão básica e análise de log em uma instância limpa.
