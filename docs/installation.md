# Installation Guide

## Requirements

- Modrinth App
- Minecraft 1.21.1
- Java compatível com Minecraft 1.21.1
- Memória recomendada: 6 a 8 GB para a instância

## Development test

1. Importe a última exportação local de desenvolvimento no Modrinth.
2. Feche o launcher e o jogo.
3. Copie config, resourcepacks, shaderpacks, options.txt e icon.png para a raiz da instância.
4. Substitua arquivos existentes.
5. Inicie sem ativar shader.
6. Execute o checklist de testing.md.

## Updating

Faça backup dos mundos. Nunca substitua uma instância estável sem preservar saves, screenshots e opções pessoais.

## Distribution

Após aprovação, exporte uma nova versão pelo Modrinth incluindo apenas arquivos necessários. Não distribua logs, saves, caches, screenshots pessoais ou arquivos de conta.

## Repository policy

Arquivos MRPack gerados não ficam versionados durante o desenvolvimento. Eles serão anexados às releases aprovadas para evitar pacotes antigos ou ambíguos na branch principal.
