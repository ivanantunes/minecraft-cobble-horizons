# CobbleHorizons Roadmap

CobbleHorizons is developed incrementally.

Each milestone introduces and validates one major layer of the modpack before development continues.

This approach makes compatibility problems, performance regressions and gameplay issues easier to identify.

---

# V0.1 — Foundation

## Objective

Build a stable technical foundation.

### Base

- Minecraft 1.21.1
- Fabric
- Cobblemon 1.7.3

### Planned Areas

- Required dependencies
- Performance optimization
- Essential QoL
- Initial configurations
- Singleplayer stability
- Multiplayer stability

### Validation

Before moving to V0.2:

- Minecraft launches reliably
- Worlds create correctly
- Cobblemon works correctly
- Pokémon spawn correctly
- Capturing works
- Battles work
- No critical errors occur
- Performance is acceptable
- Multiplayer works correctly
